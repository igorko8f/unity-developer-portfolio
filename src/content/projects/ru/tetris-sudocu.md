## Обзор проекта

Tetris Sudocu была разработана в качестве технического задания на позицию Unity-разработчика. Проект сочетает классическую укладку блоков с очисткой поля в стиле Судоку, требуя чистой архитектуры, тестируемой логики и отполированного UX.

## Технические особенности

- **Dependency Injection и реактивный поток:** Использовал **Zenject** для слабой связанности и **R3** (современный реактивный фреймворк для C#) для публикации изменений состояния поля без жёстко связанных коллбэков.
- **Кастомный инструментарий редактора:** Реализовал в инспекторе редактор матриц 5x5, позволяющий дизайнерам создавать и редактировать кастомные фигуры прямо в Unity без правки кода.
